## Обо мне

Я **Fullstack-разработчик** с **4+ годами коммерческого опыта** и основным фокусом на **Vue.js и TypeScript**. Также разрабатываю backend на **Node.js** и **PHP / Symfony**.

На **последнем месте работы** самостоятельно перенёс весь frontend CRM с **Nuxt 2 / Vue 2 и Element UI** на **Vue 3, TypeScript и PrimeVue**. Новый интерфейс внедрён и используется пользователями. Развиваю API, отчётность, разграничение доступа, редактор сценариев разговора и мониторинг качества WebRTC-звонков.

Есть опыт создания технических **2D/3D-редакторов**, браузерных **AR / WebXR-сцен**, интеграции AI API, работы с **WebSocket / WebRTC** и оптимизации производительности. Проводил code review и координировал работу части команды.

Также **разрабатываю браузерные игры** и **playable ads** на **TypeScript, Three.js и PixiJS**: игровые механики, графику, звук, мобильное управление, адаптеры платформ и сборки в самостоятельный HTML.
